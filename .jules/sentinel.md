## 2025-02-14 - Enforcing capability checks on plugin administration entry points
**Vulnerability:** In `adminmanageplugins.php`, after calling `require_login()`, the script proceeded to instantiate `peerwork_plugin_manager` and set page contexts before delegating capability checks to the manager's `execute()` method. While `execute()` checked `moodle/site:config`, entry point scripts should explicitly enforce capabilities at the boundary before constructing controllers.
**Learning:** In administrative scripts that manage plugin settings or configurations, relying solely on inner class methods for access control leaves the outer entry-point script open to unexpected state initialization. Enforcing `require_capability('moodle/site:config', context_system::instance())` immediately after `require_login()` establishes defense-in-depth and fails securely at the earliest possible moment.
**Prevention:** Always assert appropriate administrative capabilities (`moodle/site:config`) on the system context immediately after `require_login()` at the top level of admin management entry points.
