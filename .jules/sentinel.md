## 2025-05-14 - IDOR Vulnerabilities in Group/User Parameters
**Vulnerability:** Multiple Insecure Direct Object Reference (IDOR) vulnerabilities where `groupid`, `userid`, and `peerworkid` parameters were used without validating their consistency with the authenticated course or activity context.
**Learning:** `require_login($course)` ensures the current user has access to the course, but it does not prevent them from supplying an ID belonging to a different course or activity instance. Moodle's `require_capability` also doesn't automatically verify parameter-context consistency.
**Prevention:** Always validate that any ID provided in the request (like `groupid`) belongs to the expected course (e.g., using `$DB->record_exists('groups', ['id' => $groupid, 'courseid' => $course->id])`). For user IDs, verify they are enrolled in the course or are members of the relevant group. Call `require_login` as early as possible to ensure proper context initialization before performing these checks.
